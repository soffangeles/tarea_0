# Tarea 0: Registro de Alumno y Configuración

Bienvenido al curso de Simulación Estocástica. Esta actividad inicial es para registrar tus datos de contacto y el entorno en el que realizarás las prácticas del semestre.

## Instrucciones de entrega
Elige el lenguaje en el que trabajarás (Python o R) y sube el archivo correspondiente.

### Opción A: Si vas a usar Python
Crea el archivo `registro.py` con tus datos exactos:
```python
NOMBRE = "Tu Nombre Completo (como aparece en actas)"
NUMERO_CUENTA = "318123456"
CORREO = "tu_correo@ciencias.unam.mx"
CARRERA = "Actuaria"
SEMESTRE = 5
```

### Opción B: Si vas a usar R
Crea el archivo `registro.R` con tus datos exactos:
```r
nombre <- "Tu Nombre Completo (como aparece en actas)"
numero_cuenta <- "318123456"
correo <- "tu_correo@ciencias.unam.mx"
carrera <- "Actuaria"

```

---

## Pasos para la entrega
1. Ve al botón **Add file** > **Upload files**.
2. Arrastra tu archivo (`registro.py` o `registro.R`).
3. Haz clic en el botón verde **Commit changes** para guardar tu entrega.
